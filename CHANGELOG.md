# Changelog

All notable changes to Obsidify are documented in this file.

## [1.0.0]

- First public release.
- Resolve and navigate Obsidian-style `[[wikilinks]]`, including aliases, paths, and non-Markdown targets.
- Autocomplete file names after typing `[[`.
- Insert wikilinks to vault files and create missing notes from broken links.
- Backlinks, Outgoing Links, and Bookmarks views with list/tree modes and per-view sorting.
- Persistent per-vault SQLite index that survives VS Code restarts.
- Migration of settings, index, and bookmarks from the former Obsidianfy extension.
